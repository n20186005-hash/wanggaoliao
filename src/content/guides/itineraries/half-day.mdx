**路線總覽：彩虹村 → 周邊晚餐 → 望高寮夕陽 → 夜景公園。半天玩齊台中西南側的招牌景色。**

## 時間軸（以日落 18:00 為例）

| 時間 | 行程 |
| --- | --- |
| 14:30 | 抵達彩虹眷村，拍照散策 |
| 16:00 | 前往嶺東或春安路周邊簡單晚餐 |
| 17:10 | 上山前往觀景平台方向 |
| 17:30–18:00 | 望高寮夕陽 |
| 18:10 | 移動至夜景公園 |
| 18:20–19:30 | 藍調時刻＋城市燈海 |
| 19:45 | 下山，行程結束或接宵夜 |

## 交通銜接

- 彩虹眷村 → 望高寮車程約 10–15 分鐘，是這條路線成立的關鍵：距離近、方向順。
- 全程自駕或騎機車最順；無車可比較 99延或 323 的直達班次，若想留到較晚再把叫車作為回程備案，見[公車攻略](/public-transport/)。

## 各站重點

### 彩虹眷村

白天光線下色彩最飽和。假日人多，想拍空景就早點到。

### 傍晚用餐

嶺東商圈或春安路周邊快速解決，重點是趕在日落前上山。

### 望高寮夕陽 → 夜景

先在觀景平台方向看夕陽，日落後移動到夜景公園看燈海——兩個點方向不同，順序別反了，詳見[兩個觀景點差別](/park-vs-viewpoint/)。

## 注意事項

- 這條路線的成敗取決於**天氣**：出發前看[即時影像](/live-camera/)確認能見度。
- 假日彩虹眷村與望高寮都要多預留停車時間。
- 冬季日落早，整條時間軸提前一小時。
