**路線總覽：市區晚餐 → 望高寮夜景 → 台中宵夜或甜點。全程約 4–5 小時，自駕或騎機車最順。**

## 時間軸（以日落 18:00 為例）

| 時間 | 行程 |
| --- | --- |
| 16:30 | 公益路或南屯晚餐 |
| 17:40 | 出發上山（預留找車位時間） |
| 18:10 | 抵達望高寮，散步找位置 |
| 18:20–19:00 | 藍調時刻＋城市燈海 |
| 19:30 | 下山 |
| 20:00 | 市區甜點或宵夜收尾 |

冬天日落早，整條時間軸往前平移一小時左右；出發前查好當天日落時間。

## 為什麼這樣排

- **先吃再上山**：山上沒有正式餐飲，餓著肚子看夜景很掃興。
- **藍調時刻是精華**：日落後 20–40 分鐘天空最有層次，比全黑後更浪漫也更好拍。
- **宵夜收尾**：下山後 20–30 分鐘就能回到市區，甜點或宵夜讓行程有完整的結尾。

## 約會加分細節

- 帶一件外套給怕冷的另一半——山上風大，這件外套會派上用場。
- 帶野餐墊，草坡上並肩坐著看燈海，比站著舒服得多。
- 合照請在藍調時刻拍，天空還有藍色層次，人臉也還照得亮。
- 平日晚上人少，體驗比假日好很多。

## 注意事項

- 假日請把「找車位」的 20 分鐘算進時間軸，見[停車攻略](/parking/)。
- 出發前看一眼[即時影像](/live-camera/)，起霧就改成市區備案。
- 深夜下山山路請放慢速度，別讓浪漫變成驚嚇。
